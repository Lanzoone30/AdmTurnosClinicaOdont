# Sistema de Administracion de Turnos para Clinica Odontologica

El proyecto consiste en el desarrollo de un sistema de administración para una clínica odontológica, a través de una aplicación web. Su propósito es optimizar la gestión de datos de los pacientes y la asignación de turnos, con el objetivo de mejorar la eficiencia operativa y la calidad de la atención al paciente.
